ABHI DANOCH — AUTHOR WEBSITE

Files:
- index.html: website content and structure
- style.css: design and responsive layout
- script.js: mobile navigation and current year

HOW TO PREVIEW:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It will open in your browser.

BEFORE PUBLISHING, REPLACE THESE PLACEHOLDERS IN index.html:
- YOUR_AMAZON_BOOK_LINK with your Amazon book page URL
- YOUR_EMAIL_ADDRESS with an email address you want readers to contact
- Replace the “YOUR PHOTO CAN GO HERE” placeholder with your own photo if desired.

This is a static website. You can publish it free using GitHub Pages or Netlify.
